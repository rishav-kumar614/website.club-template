# website.club-template

Premium Wood-Fired Artisan Pizza website with cinematic scroll-scrubbing animations, 3D interactive Three.js pizza model, responsive menu, and modern dark-mode aesthetic.

## Features
- **Cinematic Scroll-Scrub Hero**: Frame-by-frame scroll animations using HTML5 Canvas.
- **Interactive 3D Pizza**: Built with Three.js.
- **Glassmorphic Menu & Order Sections**: Polished UI with real-time responsive design.
- **Dynamic Pizza Video Scroll Section**: Video frame sequences synchronized with page scrolling.
- **Custom Aesthetic Footer**: High-contrast typography, quick links, store hours, and site credits.

## Getting Started
Run locally with any static server or Vite:
```bash
npx vite
```
Open `http://localhost:5174` in your browser.
